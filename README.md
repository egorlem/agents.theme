# guezwhoz for Pi AI agent

## What's Inside?

A dark theme for π with a cool pastel palette and a green axis.
Built for long sessions: soft colors, a symmetric background hierarchy.

WCAG 2.1 AA — clean, with one exception: `textSoft #808080`
(4.3:1 instead of 4.5:1). It's not a flaw but a deliberate choice:
the color should recede into the background and not compete with
useful information.
